          colors?: Float32Array<ArrayBufferLike>,
      ): void

      Sets the vertex data (position and RGB colors) for the line segments.

      Parameters

      • positions: Float32Array

        A Float32Array of 3D coordinates, where each pair of coordinates is one line segment. Length must be a multiple of 6 (pairs of two 3-dimensional coordinates).

      • Optionalcolors: Float32Array<ArrayBufferLike>

        A Float32Array of RGB values in the [0, 1] range, where each triplet corresponds to a vertex color.

      Returns void

      Throws

      If positions length is not a multiple of 6 or if colors length is not a multiple of 3.
